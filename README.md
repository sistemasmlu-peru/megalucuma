# Megalücuma

Papelería católica con misión. Este repositorio reúne la marca y las herramientas internas.

- `marca/ADN-de-marca.md`: misión, visión, valores, manifiesto y paleta.
- `assets/`: logo, ornamento dorado, paleta y fotos de las agendas (Borgoña, Rosé, Olivo, Uva).
- `app-clientes/`: app interna para registrar clientes.
  - Publicada en: https://claude.ai/artifact/Gf1kF9GA6ZCnGAt15j4e3g
  - Editar `app.src.html` y regenerar con `python3 app-clientes/build.py` (incrusta logo y ornamento en `index.html`).
